# snv_rebuild/ — data slot (not in repository)

Holds the **cohort SNV master tables** under
`snv_rebuild/PT510_low/<layer>/<group>/.../<group>_master_<layer>*.csv` and the
`PT510_high/` counterpart (layer = `matched` / `benign` / `unmatched`; group =
`ALL` / `AA` / `EA` / `IN`).

- **Source:** produced by the pipeline from the per-patient inputs + annotation
  databases (see `../UPSTREAM.md`); **derived from private cohort data, shared
  separately**. Can be regenerated by the pipeline rather than shipped.
- **Read by:** `disproportion.py`, `disproportion_genes.py`, `build_paper_results.py`,
  `build_table4.py`, `build_table5.py`.

Everything in this folder except this file is git-ignored.
